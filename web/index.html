Panoptes

All-seeing PC monitor for the ESP32 "Cheap Yellow Display" (ESP32-2432S028R).

This browser has no Web Serial. Use Chrome or Edge on a desktop.

  1. Plug the board in over USB. If the agent is running (as a service too), run panoptes pause so it frees the port.
  2. Put the board in download mode: hold BOOT, tap RST, release BOOT. The screen goes dark. (The CYD's auto-reset doesn't work from a browser.)
  3. Click a Flash button below and pick the board's serial port (CH340 / USB Serial).

ST7789 panel

The panel on the reference board. Pick this first.

ILI9341 panel

If the ST7789 build shows a scrambled picture, flash this one instead.
