Panoptes

All-seeing PC monitor for the ESP32 "Cheap Yellow Display" (ESP32-2432S028R).

ST7789 panel

The panel on the reference board. Pick this first.

ILI9341 panel

If the ST7789 build shows a scrambled picture, flash this one instead.

  1. Use Chrome or Edge on a desktop. Web Serial isn't available in Firefox or Safari.
  2. Plug the board in over USB and free the port: run panoptes pause if the agent is running (as a service too), then panoptes resume once the board has rebooted.
  3. After flashing, install the host agent from the latest release and run panoptes.
